# Space Shooter 2D


Space Shooter 2D is a top down game where players pilot a spaceship, dodge enemy attacks, and collect power ups to survive increasingly challenging waves of enemies, then battle the final boss.
Built in Unity, the game features multiple enemy types, a dynamic scoring system, and engaging UI feedback for an immersive space combat experience.

# Play Online

You can play the game directly on itch.io:

https://valsalinas.itch.io/starman-shooter

# Features

- Player spaceship with movement and shooting controls

- Multiple enemy types with unique behaviors:

  - Standard, Aggressive, Smart, Dodge, Laser, Boss enemy with unique behavior

- Power-ups that enhance player abilities (ammo, shields, homing missiles, etc.)

- Waves system with increasing difficulty and messages for incoming waves

- Score and lives tracking with UI feedback

- Game over and winner sequences with persistent messages

- Flickering and animated UI for alerts and status

- Audio feedback for shooting, enemy destruction, and laser effects

# How to Play

- Use arrow keys or WASD to move the spaceship.

- Press spacebar to shoot.

- Avoid enemy fire and collisions.

- Collect power-ups to improve your abilities.

- Survive waves of enemies until the boss appears.

- After defeating the boss, the WINNER message is displayed.

- Press R to restart the game or Escape to quit.

# Installation

Clone the repository:
```bash
git clone https://github.com/yourusername/SpaceShooter2D.git
```

Open the project in Unity (2019.4+ recommended).

Open the Main scene and press Play to start the game.

# Controls

*   Move up: `W` / `↑`
*   Move down: `S` / `↓`
*   Move left: `A` / `←`
*   Move right: `D` / `→`
*   Shoot: `Spacebar`
*   Restart game: `R`
*   Quit game: `Escape`
